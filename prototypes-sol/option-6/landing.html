Chapter 1

Local inference starts with one install.

Load a GGUF model directly from Hugging Face, then stream or complete a response.

1

Add NobodyWho

Install with uv or pip.

2

Pass a model path

Use Hugging Face or local storage.

3

Ask

Read tokens as they arrive or return the full response.

quickstart.py
from nobodywho import Chat

chat = Chat(
    'huggingface:NobodyWho/
    Qwen_Qwen3-0.6B-GGUF/
    Qwen_Qwen3-0.6B-Q4_K_M.gguf'
)

response = chat.ask('Is water wet?')
print(response.completed())
Chapter 2

Privacy is a location. Keep computation close.

Private

Prompts and outputs stay in local memory. Nothing has to be uploaded or logged by a cloud provider.

Offline

Use models on a flight, inside a secure environment, or anywhere connectivity is unreliable.

Fast on available hardware

Optimized kernels use Metal, CUDA, Vulkan, integrated graphics, and mobile chips.

Use a shared engine for language, audio, vision, retrieval, and tool use.

Language

Chat, streaming, structured output, and tool calling.

Knowledge

Audio

Vision

Multimodal inputs with compatible local models.

Bindings
