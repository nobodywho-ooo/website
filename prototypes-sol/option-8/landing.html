Start / Python 2.0.0

Two commands. One local model.

Install the library, point to a GGUF model on Hugging Face, and generate on your own machine.

Read the Python guide
quickstart.py
from nobodywho import Chat

chat = Chat('huggingface:NobodyWho/Qwen_Qwen3-0.6B-GGUF/Qwen_Qwen3-0.6B-Q4_K_M.gguf')
response = chat.ask('Why run locally?')

for token in response:
    print(token, end='', flush=True)
