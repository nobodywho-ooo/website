Local inference, ready to use.

Add private text, vision, and speech models to your software without running an inference server.

GGUF modelsMetalCUDAVulkanOffline
Install NobodyWho
uv add nobodywho↵
quickstart.py
from nobodywho import Chat

chat = Chat(
  'huggingface:NobodyWho/
  Qwen_Qwen3-0.6B-GGUF/
  Qwen_Qwen3-0.6B-Q4_K_M.gguf'
)

response = chat.ask('Is water wet?')
print(response.completed())
Runtime

The network is optional. The capability is not.

NobodyWho runs models in the same environment as your application.

Private

Inputs and outputs stay in local memory rather than passing through a cloud API.

No upload

Offline

Inference continues on flights, in secure environments, and during network outages.

No connection

Hardware-aware

Optimized kernels use Metal, CUDA, Vulkan, integrated graphics, and mobile chips.

Local acceleration

Open

Use compatible GGUF models from Hugging Face or local storage.
