Install. Pick a model. Ask.

NobodyWho downloads compatible GGUF models from Hugging Face and runs them where your code runs.

Your first local response.

Stream tokens as they arrive or return the complete response as a string.

terminal uv add nobodywho
quickstart.py
from nobodywho import Chat

chat = Chat(
  'huggingface:NobodyWho/
  Qwen_Qwen3-0.6B-GGUF/
  Qwen_Qwen3-0.6B-Q4_K_M.gguf'
)

response = chat.ask('Is water wet?')
print(response.completed())
