What changes

The prompt does not leave. The answer does not wait for a server.

A small API with a full runtime.

Load a GGUF model from Hugging Face, ask a question, stream the response.

from nobodywho import Chat

chat = Chat(
  'huggingface:NobodyWho/
  Qwen_Qwen3-0.6B-GGUF/
  Qwen_Qwen3-0.6B-Q4_K_M.gguf'
)

response = chat.ask(
  'Is water wet?'
)

for token in response:
  print(token, end="")
