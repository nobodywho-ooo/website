OPERATING INSTRUCTION / PYTHON

Install. Load. Ask.

Point NobodyWho at a GGUF model on Hugging Face. The model downloads once and runs locally.

uv add nobodywho

Read complete instructions

NW_QUICKSTART.PY2.0.0
from nobodywho import Chat

chat = Chat(
  'huggingface:NobodyWho/
  Qwen_Qwen3-0.6B-GGUF/
  Qwen_Qwen3-0.6B-Q4_K_M.gguf'
)

response = chat.ask(
  'Is water wet?'
)

for token in response:
  print(token, end='', flush=True)
