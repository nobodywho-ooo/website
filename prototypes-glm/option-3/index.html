One API, six languages.

Load a model, ask a question, stream the answer. The same three steps everywhere.

from nobodywho import Chat

chat = Chat("hf://NobodyWho/Qwen_Qwen3-0.6B-GGUF")
response = chat.ask("What is the capital of Denmark?")

# print each token as it is generated
for token in response:
    print(token, end="", flush=True)

# or get the entire response as a single string
full_response = response.completed()
import ai.nobodywho.Chat
import kotlinx.coroutines.runBlocking

val chat = runBlocking { Chat.fromPath(modelPath = "./model.gguf") }
val response = runBlocking {
    chat.ask("What is the capital of Denmark?").completed()
}

It listens. It speaks.

Speech-to-text and text-to-speech ship with the engine. Same local guarantee.

Speech to text

Whisper models in ONNX format, straight from Hugging Face.

from nobodywho import SpeechToText

stt = SpeechToText(source="hf://onnx-community/whisper-base")
text = stt.transcribe_file("recording.mp3").completed()

# buffers work too, mono i16 PCM at any sample rate
text = stt.transcribe_pcm(samples, sample_rate=16000).completed()

Text to speech

Kokoro, Pocket TTS, or Supertonic. WAV bytes, ready to play.

from nobodywho import TextToSpeech

tts = TextToSpeech(
    source="hf://NobodyWho/Kokoro-82M",
    voice="bf_emma",
    language="en-gb",
)
wav = tts.synthesize("Hello from NobodyWho!")
